# NBA Player Props Framework V2.2

The November 3, 2026 consolidated rewrite is the governing baseline, confirmed by the user on November 6, 2026. It supersedes conflicting November 2 V2.2 provisions. This is a documentation import, not analytical implementation.

The [authoritative reference](source/nba-player-props-v2.2-2026-11-03.txt) is preserved verbatim. Its complete text governs; summaries and navigation do not replace it. Original source metadata and checksums are in [the manifest](../../manifests/framework-sources.json). Earlier sources remain unchanged in `source/` for comparison.

The reference preserves all five stages; PTS, REB, AST, 3PM, PR, PA, RA and PRA; DC and DARKO responsibilities; compatible DARKO normalization to DC minutes; the four-factor eight-point rubric; independent opportunities; market evaluation; finalist comparisons; lock checks; archive and postgame requirements. Steals, blocks and stocks remain excluded. DPM is not a box-score projection. No new scoring factors, projections or versions are introduced.

## Exact grading eligibility extract

The following table and A-range requirements reproduce November 3 §5D. They are documentation, not automation.

| Model relationship | Independent rubric | Grade eligibility |
| --- | --- | --- |
| Agree | 7–8/8 | A-range if market advantage is meaningful |
| Agree | 5–6/8 | B-range |
| Agree | 3–4/8 | C-range |
| Agree | 0–2/8 | D / Pass |
| Disagree | 7–8/8 | B+ maximum |
| Disagree | 5–6/8 | B or lower |
| Disagree | 0–4/8 | C or lower / Pass |
| Unresolved | Any | No automatic A-range eligibility |

These are eligibility bands, not automatic final grades.

To receive an A-range grade:

1. DC and normalized DARKO must support the same direction at the selected line.
2. Independent validation must score at least 7/8.
3. Minutes and role must be credibly established.
4. Statistical opportunity ownership must have strong independent support.
5. The exact line must offer meaningful advantage relative to uncertainty.
6. No material unresolved contradiction may undermine the selection.
7. Relevant game scripts and failure scenarios must have been considered.

An 8/8 does not automatically create an A+.

**B+ remains the maximum grade for genuine directional model disagreement.** Strong evidence and an attractive threshold do not remove this ceiling. Weak evidence or inadequate margin requires downgrade or Pass. See source §§3B, 5D and XI. Neither neutral nor missing model information is silently treated as agreement.
